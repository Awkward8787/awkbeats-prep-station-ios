# AwkBeats Prep Station (iPhone)

Native SwiftUI port of the Prep Station desktop app (Awkward8787/awkbeats-prep-station, PR #1 @ 0dec168).
Powered by AwkBeats. Bundle `com.awkbeats.prepstation`, ASC app 6825604913, SKU `awkbeats-prepstation-ios`.

## Build
    xcodegen generate
    xcodebuild test -project PrepStation.xcodeproj -scheme PrepStation -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath build/DD
    scripts/screenshots.sh          # -demo library screenshots into screenshots/
    scripts/archive-ios.sh          # Release archive + App Store Connect export (local Xcode, automatic signing)

## Phase 1 features
- Import MP3, WAV, FLAC, M4A, AIFF from Files (multi-select) or the share sheet / "Open in" (document types).
  Existing tags (title, artist, producer, genre, BPM, key, cover) are kept on import.
- On-device key (desktop algorithm, 1:1 port) and BPM (spectral-flux tempo + grid regression; see BpmDetector.swift).
- Reference chord and sustained drone for the key; play the beat and the drone together to check by ear.
- Metadata: title, producer (default from Settings, first-launch prompt), artist, genre, BPM (½× / 2× / typed), key (24-key picker), status, notes, cover art (square-cropped to 1500 px JPEG).
- Save tags into the file: ID3v2.3 (MP3), RIFF INFO + `id3 ` chunk (WAV), NAME/AUTH + `ID3 ` chunk (AIFF), Vorbis comments + PICTURE (FLAC), iTunes atoms (M4A). Share/export the tagged file.
- Catalog in SwiftData with search (title, artist, producer, genre, key, Camelot, BPM, notes), status filter chips, sort.

## Launch flags (simulator screenshots)
`-demo` (in-memory library of synthetic beats, real detection), plus `-demoDetail`, `-demoBottom`, `-demoFilter`, `-demoEmpty`, `-demoSettings`.

## Test audio
`PrepStationTests/Fixtures` has 20 synthetic beats with known key/BPM encoded as MP3/WAV/FLAC/M4A/AIFF
(generated by `testaudio/gen.py` + `gen2.py`; answers in `truth.json`). `AccuracyTests` prints the table.
